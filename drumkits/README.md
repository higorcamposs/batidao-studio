Biblioteca inicial de samples para o beat maker. As fontes abaixo foram baixadas em 03/09/2026 e mantidas com seus arquivos de licença/readme para auditoria.

Total baixado: 747 arquivos de áudio, aproximadamente 275 MB.

## Uso no HHF

Os arquivos estão em `sources/`. O MVP pode apontar o catálogo para essas pastas ou copiar somente os one-shots necessários para o bundle final. Preserve os arquivos `README.md`, `LICENSE` e a origem junto do catálogo.

## Regra jurídica do MVP

Não tratar “free”, “royalty-free” ou “grátis” como autorização de redistribuição. Só incluir no bundle do HHF fontes com autorização explícita para uso comercial e redistribuição, como CC0/domínio público, e registrar a URL e a licença no catálogo. Esta documentação não substitui revisão jurídica.
